About the Project

I am a Finance student at Rogers State University. I created this website as an AI-assisted finance project to demonstrate how common financial calculations can be performed in an interactive web application.

The project combines finance concepts with HTML, CSS, and JavaScript. AI was used to help plan the site, write and review the code, troubleshoot the calculators, and verify the financial formulas.

The goal is to provide simple tools that clearly show both the inputs and results for several widely used investment measures.

Calculators

Financial Analysis

Enter values below and select Calculate. Percent inputs should be entered as normal percentages, such as 8 for 8%.

01

Holding-Period Return

HPR = (Ending Price − Beginning Price + Dividends) ÷ Beginning Price

Result will appear here.
02

Annualized Return

Annualized Return = (1 + HPR)365 ÷ Days Held − 1

Result will appear here.
03

Stock Beta

Beta = Covariance(Stock, Market) ÷ Variance(Market)

Result will appear here.
04

Sharpe Ratio

Sharpe Ratio = (Portfolio Return − Risk-Free Rate) ÷ Portfolio Volatility

Result will appear here.
05

Correlation

Correlation = Covariance(X, Y) ÷ (Standard Deviation X × Standard Deviation Y)

Result will appear here.

Calculation Notes

Beta and correlation require equal-length return series. Percentage returns can be entered as values such as 2, 4, and -1 to represent 2%, 4%, and -1%. For beta, using percentage values or decimals produces the same beta because the common scaling factor cancels in covariance divided by variance.

The Sharpe ratio calculator expects annual return, annual risk-free rate, and annual volatility measured over the same annual period.
