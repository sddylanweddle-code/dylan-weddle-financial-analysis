# Dylan Weddle Financial Analysis

A static finance calculator website designed for GitHub Pages.

## Files
- `index.html` — all website pages/tabs and calculator inputs
- `styles.css` — responsive styling
- `script.js` — navigation and financial calculations

## Included financial calculations
1. Holding-Period Return
2. Annualized Return
3. Stock Beta
4. Sharpe Ratio
5. Correlation

## Before submitting
Open `index.html`, go to the Contact page, and replace the placeholder text with the email address you want displayed.

## GitHub Pages publishing
1. Create a new GitHub repository. A name such as `dylan-weddle-financial-analysis` works well.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open repository **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Use the GitHub Pages URL provided by GitHub as your project submission URL.

Because the site is fully static, it requires no paid hosting or API key.
